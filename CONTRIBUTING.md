# Contributing

Thanks for helping map the Turkish MCP ecosystem.

## Adding an entry

1. Fork this repository and edit **both** `README.md` and `README.tr.md` (keep them in sync).
2. Add your entry to the end of the matching section, in this exact format:

   ```markdown
   - [name](https://github.com/owner/repo) - One-sentence description of what it does.
   ```

   Start the description with a capital letter and end it with a period.
3. If no section fits, propose a new one in your pull request.

## Bar for inclusion

- **Open source** with a public repository.
- **Works** — a real, runnable MCP server (or, for the *Related Tools* section, a CLI/skill/library built for agents).
- **Turkish** — it serves Turkish data or a Turkish domain (law, finance, government, academia, business, …).

## Not sure?

Open a pull request or an issue anyway — a short discussion beats a missing entry. Keep descriptions factual and free of marketing language.
